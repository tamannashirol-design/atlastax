# Synthetic test documents

The only place in the project where PDFs (and test images) may live.
Everything here is made up and marked SAMPLE. SSNs and ITINs use only
123-45-6789, 000-00-0000, 111-11-1111 or 555-55-5555.

`npm run check:files` enforces this (it runs before every build).
Never add a real document, even a redacted one.
